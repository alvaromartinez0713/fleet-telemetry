Fleet Platform · what is missing

Audited against the nine platform sections and the modules the backend already has. Three things are missing entirely — and the biggest one is alerting delivery.

Missing 3

  • missing
    Alert delivery & notification log. The platform knows if the alerting worker is alive, but not whether a notification reached a human. Email, push, SMS and webhook outcomes, retries, quiet-hour suppressions. Without it, a failed page looks exactly like an ignored alert. Designed in board 47.
  • missing
    Rule evaluation health, per rule. Today only the worker has a card. What matters is which rule is slow, which one is silent when it should fire, and how far behind the evaluation window it is. Panel included in board 47.
  • missing
    Retention, export and cost. How long events and logs live, what a tenant's storage costs, and how to export a window for an audit. This is a sales question before it is a UI question.

Present, but should move

  • fold
    Partitions — it is a tab inside Pipeline, not a section of its own. Six partitions do not deserve nine menu entries.
  • fold
    Schema & limits — a reference table that belongs beside Ingest, where the contract is enforced.
  • merge
    Workers + Assistant — same question: is this thing running, and how fast. One surface, two sections.
  • keep
    Gateway & ingest, Pipeline, Data health, Logs & traces, Payload inspector — each answers a distinct question and none is a shortcut for another.

The v2 shape, if it is applied

  • 1
    Ingest & pipeline
    gateway outcomes, stage funnel, partitions, schema limits
  • 2
    Runtime
    workers and assistant, evaluation and delivery health, notification log
  • 3
    Evidence
    logs, traces, payload inspector — the bytes, searchable
  • +
    Persistent agent
    ⌘K on every surface, answers with the tool that produced them
  • +
    Query bar
    same box takes natural language or a structured query, no second tool
  • +
    Links to Ops
    every device fact offers “see it as a dispatcher would”
The same rule as Ops, applied to engineering: panels for state, the agent for intent, the inspector for evidence. Platform keeps one extra obligation Ops does not have — it must be able to prove what the system did, which is why the notification log and the per-rule evaluation table are not optional extras.

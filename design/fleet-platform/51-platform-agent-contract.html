Platform agent · read-only by contract

The Ops assistant proposes actions for a human to approve. The Platform assistant has no actions at all — it answers, correlates and cites. That asymmetry is the whole point.

✓ It can all reads

  • ✓
    Query any surface. Stages, partitions, workers, rules, deliveries, logs, traces, payloads.
  • ✓
    Correlate by trace id. From one 422 back to the device, the batch and every span of that request.
  • ✓
    Explain a spike. “4xx at 11:04 → four devices drifted their clock → 3 109 events rejected → retried byte-identical.”
  • ✓
    Write the query for you. It composes a filter you can copy, but it does not run writes.
  • ✓
    Cite the panel. Every claim carries the section it came from, so you can verify it.

✗ It cannot no writes

  • ✗
    Resend or release an event. Held and dead-letter events move only by a human command, with a footprint.
  • ✗
    Replay against a build. Reproducing traffic is an operation, not a question.
  • ✗
    Resend a notification. It can tell you the SMS never left; sending it again is your call.
  • ✗
    Change a rule, a limit or a config. Configuration has one path: a diff a human approves.
  • ✗
    Restart a worker or scale anything. No infrastructure verbs at all.

⋮ How it stays honest

  • •
    Same data path. It reads the modules the panels read; there is no second source of truth.
  • •
    Says when it is degraded. If a tool fails it answers from cached state and declares it — the circuit breaker is in the UI.
  • •
    No invented identifiers. Device ids, seq numbers and trace ids come from tool results, never from prose.
  • •
    Queries are logged. Who asked what, and which panels were read — the only audit trail a read-only agent needs.
  • •
    Never blocks the panels. If the model is down, Ingest, Runtime and Evidence still render.

Four things it is allowed to be

Explainer read
“What does the watermark do?” — answers from the running build, not from documentation that drifts.
Correlator read
Joins device, batch, span and notification into one story when the panels are four screens apart.
Query builder read
Turns a sentence into a filter you can copy into the search bar. It never runs the query for you.
Second opinion read
When you think you found the cause, it checks the evidence and contradicts you if the numbers do not agree.
The asymmetry that matters: in Ops the agent saves a dispatcher a phone call; in Platform it saves an engineer a search. But Ops actions are recoverable (a call, a silence) while platform ones are not (a replay writes, a resend duplicates, a scale-up costs money). So Platform gets a copilot with no hands — and that is a feature, not a limitation to fix later.
